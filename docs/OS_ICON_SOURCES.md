# Operating-system icon sources

Mist Universal bundles operating-system and distribution marks only to identify official download resources in the catalog. All names and logos remain trademarks of their respective owners.

## Sources

- Ubuntu, Fedora, Debian, Linux Mint, Pop!_OS, openSUSE, Red Hat, Rocky Linux, Zorin OS, Steam, CachyOS, Garuda Linux, Arch Linux, Lubuntu, Xubuntu, MX Linux, Alpine Linux, elementary OS, and Asahi Linux: [Simple Icons](https://simpleicons.org/)
- Windows 10, Windows 11, EndeavourOS, Puppy Linux, and Peppermint OS: [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons)
- Bazzite: [official Bazzite site](https://bazzite.gg/)
- Nobara Linux: [official Nobara site](https://nobaraproject.org/)
- antiX: [official antiX site](https://antixlinux.com/)
- Bodhi Linux: [official Bodhi Linux site](https://www.bodhilinux.com/)

The artwork is stored locally in `Mist/Assets.xcassets`; the app does not download icons at runtime.
